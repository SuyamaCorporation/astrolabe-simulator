## アストロラーベ（星盤）シミュレータ

中世の天文航法器アストロラーベをCanvas上で再現し、緯度と日時から天球・太陽・主要恒星20個の高度・方位を視覚化する天文教育ツール。

### 機能
- 緯度（-90〜90°）と日時（UTC）の設定でリアルタイム天球更新
- 太陽の高度・方位・日の出・日没時刻（UT）の算出表示
- 主要恒星20個の現在高度・方位を星盤上にプロット（星等に応じたサイズ変化）
- 東京・ロンドン・赤道のクイックセットボタン
- 恒星時（LST）表示・恒星一覧（高度順・地平線上/下で色分け）

### 技術
- 静的SPA（index.html単体）
- Tailwind CSS CDN
- Canvas API（天球座標変換・太陽黄経計算・時角計算）
